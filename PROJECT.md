# РАССВЕТ — локальная версия

Учебный веб-проект спутникового оператора. Текущая версия запускается на компьютере и не загружается на хостинг. Для входа используются почта и пароль; письма не отправляются. Все изображения и шрифты локальные: системный Segoe UI / system-ui и запасные системные гарнитуры.

## Запуск

Требуется Node.js 24+. Зависимости в текущей папке установлены.

Откройте `Start-Rassvet.cmd` из родительской папки двойным щелчком или выполните в этой папке:

```powershell
npm run local
```

Скрипт собирает приложение, проверяет таблицы локальной базы, применяет недостающие первоначальные миграции и запускает сервер. Откройте напечатанный адрес — обычно `http://127.0.0.1:5173/`. Если порт занят, сервер может выбрать следующий порт. Держите окно сервера открытым; для остановки нажмите `Ctrl+C`.

При первом запуске после копирования проекта на другой компьютер сначала установите зависимости:

```powershell
npm ci
npm run local
```

Интернет нужен для первоначальной установки пакетов и реального замера в разделе «Проверка скорости». Работа остальных локальных функций после установки не требует облачной базы, ChatGPT, Cloudflare-аккаунта, внешних шрифтов, почтового сервиса или загрузки изображений из сети. Локальный эмулятор Cloudflare D1 хранит SQLite на диске. Демонстрационная модель тарифов работает офлайн.

Если база уже подготовлена и вы редактируете код, достаточно:

```powershell
npm run dev -- --hostname 127.0.0.1
```

По умолчанию проект запускается на loopback и не доступен другим устройствам сети. Не добавляйте `--hostname 0.0.0.0`, если не планируете сетевой доступ.

## Пользовательские возможности

Обновлённое оформление, поведение меню при наведении, управление с клавиатуры и локальные иконки Google Material Symbols описаны в [NAVIGATION-DESIGN.md](NAVIGATION-DESIGN.md).

Приложение расширено отдельными страницами, сравнением тарифов, калькулятором, пошаговым подключением и редактированием своих заявок. Карта маршрутов и сценарии проверки находятся в [PAGES.md](PAGES.md). Оранжевый акцент заменён на синий в обеих темах, включая логотип, favicon, кнопки и карту.

- Светлая и тёмная темы; выбор сохраняется на устройстве и применяется до отрисовки страницы. По умолчанию учитывается системная тема.
- Крупнее текст и подписи, более контрастные второстепенные цвета, читаемые формы в обеих темах.
- В светлой теме весь текст чёрный, в тёмной — белый, включая подсказки, цены, формы, карту и подменю. Фоны кнопок, активных переключателей и надписей поверх изображений адаптированы к теме. Недоступные кнопки отличаются фоном и пунктирной рамкой без снижения непрозрачности текста.
- Первый экран с крупной фотографией, выбором домашнего, мобильного или бизнес-продукта и вводом адреса. Ориентир по композиции и пути подключения — [Starlink](https://starlink.com/ru-kz); бренд, материалы и учебные характеристики РАССВЕТ самостоятельные.
- Три тарифа, годовая скидка, расчёт комплекта и стоимости при подключении.
- Карта с географическим контуром России из Natural Earth, выбором городов и демонстрационной проверкой адресов. SVG и геометрия локальные; источник и подготовка описаны в [MAP-DATA.md](MAP-DATA.md).
- Регистрация, вход, сохранение сессии, выход; показать/скрыть пароль; проверка повторного пароля и понятные ошибки.
- Защищённый кабинет: профиль, свои заявки, отмена заявки, поддержка и история обращений.
- Контекст подключения сохраняется при переходе к входу.
- Проверка скорости: настоящий замер текущего интернета через Cloudflare, отдельная демонстрационная модель трёх подписок и условий, тариф по последней собственной неотменённой заявке, график, остановка, история текущей страницы и текстовый отчёт. Объём, методика и проверки описаны в [SPEEDTEST.md](SPEEDTEST.md).
- Подменю основных разделов, страницы сценариев и руководств; дополнительная навигация по оборудованию.
- Четыре концептуальные модели Mini, Standard, Pro и Mobility с реалистичными изображениями, характеристиками, сравнением и готовыми сборками. Конфигуратор рассчитывает крепление, кабель, роутер, резервное питание и кейс; выбранный состав сохраняется в заявке и доступен для редактирования.
- Каждая из девяти карточек аксессуаров имеет собственное реалистичное изображение: три крепления, два кабеля, Mesh, Pro, резервное питание и кейс. Изображения локальные, в оптимизированном WebP; их описание и промпты — в `ACCESSORY-ASSETS.md`.
- При регистрации видны шесть требований к паролю: длина 10–128, заглавная и строчная латинские буквы, цифра, спецсимвол, отсутствие пробелов и невидимых символов. Каждый индикатор обновляется при вводе; повтор пароля проверяется отдельно. Те же требования применяет сервер. Для входа в ранее созданные аккаунты новые требования к составу пароля не применяются.

## Как проверить

1. Нажмите значок солнца/луны в шапке. Проверьте главную и формы в обеих темах; обновите страницу — выбор сохранится.
2. Откройте «Личный кабинет» → «Создать аккаунт». Введите имя, вымышленную почту и пароль, удовлетворяющий всем шести подсказкам, затем совпадающий повтор. Не используйте свой настоящий пароль от почты.
3. После регистрации откроется кабинет. Измените профиль, создайте учебную заявку, отправьте обращение.
4. Выйдите из аккаунта и войдите по той же почте и паролю. Данные должны сохраниться.
5. Создайте второй аккаунт с другой почтой: он не должен видеть данные первого.

Email — только логин. Верификации адреса и рассылок нет. Восстановление пароля по почте не реализовано. Система не просит пароль от настоящего почтового ящика.

Автоматические проверки:

```powershell
npm test
npm run typecheck
npm run build
node scripts/local.mjs --prepare-only
```

Тесты выполняются с настоящим SQLite в памяти. Они проверяют цены, валидацию, хеширование и проверку паролей, регистрацию, дубликаты почты, сессии и их отзыв, ограничение неудачных попыток, CSRF-проверку происхождения запросов, cookie, безопасные возвратные URL и изоляцию заявок/профиля/обращений.

Визуальная и end-to-end проверка в автоматизированном браузере ограничена: сохранённая настройка доступа блокирует localhost. Это не отменяет успешные сборку, проверку типов, unit/integration-тесты SQLite и подготовку локальной базы. Внешний вид и полный путь в браузере нужно дополнительно проверить вручную.

## Данные и безопасность

Локальная база находится в `.wrangler/state/`. Не удаляйте эту папку, если нужно сохранить аккаунты и заявки. Для переноса остановите сервер и скопируйте её вместе с проектом. Эта папка исключена из Git.

Пароли хешируются PBKDF2-SHA256 с уникальной случайной солью; исходный пароль в базе не хранится. Случайный токен сессии хранится в HttpOnly/SameSite cookie, в базе находится только его SHA-256. Есть срок сессии, отзыв при выходе и ограничение неудачных попыток. На локальном HTTP cookie работает без флага Secure; при HTTPS он добавляется. Записывающие запросы проверяют Origin.

Каждое обращение к данным ограничено идентификатором текущей серверной сессии. Переданный браузером `userId` игнорируется; сумма заказа заново рассчитывается по серверному каталогу. Локальное хранилище браузера используется только для темы.

В этой версии нет зависимости от прежнего входа ChatGPT. Старые строки прежнего типа идентификации в локальной базе не удаляются и не присваиваются новым аккаунтам автоматически.

## Архитектура

React 19, TypeScript, Vinext/App Router, Vite 8, локальный runtime Workers + D1/SQLite, Drizzle ORM и Lucide.

| Путь | Назначение |
| --- | --- |
| `components/Landing.tsx`, `CoverageMap.tsx` | Главная, продукты, тарифы и карта |
| `app/globals.css`, `app/themes.css` | Основные стили, темы, контраст и адаптивность |
| `components/ThemeToggle.tsx` | Переключение и сохранение темы |
| `components/AuthForm.tsx`, `AuthScreen.tsx` | Вход и регистрация |
| `lib/auth-core.ts`, `session.ts`, `cookies.ts` | Хеширование, аккаунты и сессии |
| `lib/request.ts`, `api.ts` | Проверка запросов и авторизация |
| `app/api/auth/*`, `app/auth/page.tsx` | Маршруты аутентификации |
| `components/Account.tsx`, `OrderModal.tsx` | Кабинет и подключение |
| `lib/records.ts`, `domain.ts` | Доступ к своим данным, тарифы и валидация |
| `db/schema.ts`, `drizzle/` | Схема и миграции |
| `scripts/local.mjs` | Повторяемая локальная подготовка и запуск |

Не изменяйте применённые миграции. Для будущих изменений генерируйте новую миграцию, применяйте её отдельно и обновляйте локальный сценарий подготовки. Текущий сценарий знает миграции 0000–0002 и не сбрасывает существующие данные. Третья миграция добавляет nullable-поле `equipment_config` к заявкам; старые заявки работают без него.

## Учебные ограничения

Тарифы, характеристики оборудования и покрытие иллюстративны. Реальных подключений, оплаты, доставки, биллинга трафика и службы поддержки нет. Заявки и обращения сохраняются локально. Проект не связан со Starlink и БЮРО 1440.
