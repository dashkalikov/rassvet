# Страницы и новые возможности

Все адреса открываются локально после `npm run local`. К пути добавляется адрес сервера, обычно `http://127.0.0.1:5173`.

| Путь | Возможности |
| --- | --- |
| `/` | Главная страница, выбор сценария и карточки переходов во все основные разделы |
| `/plans` | Фильтры по назначению и бюджету, месяц/год, сравнение тарифов, калькулятор расходов за первый год |
| `/speedtest` | Реальный замер текущего интернета через Cloudflare, модель трёх подписок, тариф из своей заявки, график, остановка, история и отчёт |
| `/plans/home`, `/plans/travel`, `/plans/business` | Подробные сценарии, тариф и совместимые модели |
| `/equipment` | Фотокаталог Mini, Standard, Pro и Mobility, поиск и фильтры |
| `/equipment/mini`, `/equipment/standard`, `/equipment/pro`, `/equipment/mobility` | Реалистичные изображения с увеличением, характеристики, комплектация и совместимые тарифы |
| `/equipment/configure` | Модель, крепление, кабель, роутер, резервное питание и кейс; расчёт, скачивание сметы и ссылка на сборку |
| `/equipment/bundles` | Готовые сборки для дома, путешествий и бизнеса |
| `/equipment/compare` | Сравнение выбранных моделей в одной таблице |
| `/equipment/accessories` | Девять карточек с реалистичными изображениями, фильтры по категориям и добавление в конфигурацию |
| `/equipment/installation` | Подготовка к установке и интерактивный чек-лист |
| `/guides`, `/guides/<slug>` | Руководства по установке, Wi-Fi, аккаунту и выбору комплекта |
| `/coverage` | Географический контур России из Natural Earth, масштаб, слои, выбор городов, проверка адреса и переход к заявке |
| `/technology` | Интерактивное объяснение пути сигнала из четырёх этапов |
| `/support` | Поиск по базе знаний, категории, обращение и проверка ответа локального сервера |
| `/connect` | Пошаговое подключение: тариф → адрес → проверка условий → сохранение заявки |
| `/auth` | Вход и регистрация, живые индикаторы требований к паролю и совпадения повтора |
| `/account` | Обзор личного кабинета |
| `/account/orders` | Свои заявки, переход к деталям, отмена |
| `/account/orders/<id>` | Детали одной своей заявки, редактирование, отмена и скачивание текстовой сводки |
| `/account/support` | Новое обращение и история своих обращений |
| `/account/profile` | Редактирование имени и телефона |
| `/privacy` | Данные, условия и ограничения учебного приложения |

В шапке есть раскрывающиеся подменю; на узких экранах — группы в мобильном меню. Раздел оборудования имеет дополнительную навигацию. У разделов кабинета собственные URL. При переходах работают прямые ссылки и история браузера. Недоступная или чужая заявка возвращает страницу 404.

## Короткий сценарий проверки

1. На главной переключите тему. Проверьте шапку, кнопки, карту и страницы: в светлой теме текст чёрный, в тёмной белый. Проверьте подсказки форм, цены, подменю, выбранные фильтры и подписи поверх изображений. Синий сохранён для декоративных акцентов и рамок.
   На первом экране активная и неактивные карточки имеют одинаковую прозрачность и размытие 8 px. Цвет текста соответствует теме. Нажмите на описание или пустое место карточек «Дом», «В пути», «Бизнес»: на широком экране столбцы плавно меняют ширину за 0,85 секунды, содержимое появляется постепенно, а фон одновременно перетекает в новую фотографию. Место под развёрнутую форму зарезервировано заранее, поэтому её промежуточная ширина не меняет высоту фотографии. На узком экране три карточки сохраняют порядок и плавно раскрываются по вертикали. Быстро переключите несколько карточек, особенно вернитесь с «Бизнес» и «В пути» на «Дом»: фон не должен сдвигаться или кратко темнеть. Проверьте также смену фото в разделе решений ниже. При включённом в системе уменьшении движения переключение выполняется без анимации. Поле адреса и кнопка «Начать» работают отдельно. Клавишей Tab можно выбрать карточку, Enter или пробел раскрывает её; поля неактивных карточек не получают фокус.
2. Перейдите в «Тарифы». Измените бюджет и назначение, отметьте карточки для сравнения. Переключите годовую оплату и проверьте сумму в калькуляторе.
   Ползунок бюджета занимает отдельную строку на всю ширину панели, включая мобильный экран. Перетаскивание и клавиши со стрелками меняют значение и список тарифов.
3. Откройте подменю «Оборудование», страницу модели и увеличенное изображение. Сравните несколько моделей, выберите готовую сборку и измените её в конфигураторе. Проверьте смену цены при выборе крепления, кабеля, роутера и дополнений. Скачайте смету; откройте скопированную ссылку на сборку.
4. На карте выберите город, затем перейдите к заявке. Адрес должен перенестись в форму.
   Вместо прежнего условного многоугольника показаны границы России, включая острова. Проверьте увеличение, уменьшение, сброс и оба слоя. На узком экране города доступны кнопками под картой. Данные хранятся в проекте; описание источника находится в [MAP-DATA.md](MAP-DATA.md).
5. Перейдите из конфигуратора к подключению. Если вход ещё не выполнен, создайте аккаунт. Вводите пароль постепенно: шесть требований отмечаются отдельно; несовпадающий повтор показывает ошибку. Кнопка создания доступна при выполнении всех требований и совпадении паролей. Тариф, адрес и состав комплекта сохраняются при возврате к заявке после входа.
6. После отправки откройте заявку. Проверьте сохранённый состав комплекта. Измените тариф, период, адрес и оборудование, сохраните и обновите страницу. При смене тарифа доступны только совместимые модели; сумма пересчитывается сервером. Скачайте текстовую сводку.
7. Отмените заявку: она остаётся в истории, а редактирование становится недоступным.
8. Найдите материал в поддержке, проверьте ответ локального сервера и отправьте учебное обращение. Откройте его в `/account/support`.
9. Нажмите «Назад» в браузере и обновите одну из внутренних страниц: нужный раздел должен сохраняться.

## Реальные действия и учебные данные

Раздел «Проверка скорости» подробно описан в [SPEEDTEST.md](SPEEDTEST.md). Реальный режим обращается к серверу Cloudflare по кнопке; сравнение спутниковых подписок является отдельной явно обозначенной моделью. Автоматический тариф берётся только из собственных неотменённых заявок пользователя.

Аккаунты, профиль, заявки, состав оборудования, правки заявок и обращения записываются в локальную базу. Цена пересчитывается на сервере, доступ ограничен текущим пользователем. Миграция `0002_flimsy_gamora.sql` добавляет к заявкам поле конфигурации; запуск `npm run local` применяет её при необходимости без удаления старых данных. Заявки прежних версий остаются доступны.

Карта покрытия, тарифы и оборудование иллюстративны. Проверка сервера на странице поддержки измеряет фактическое время ответа локального приложения и не является тестом спутникового интернета. Фильтры, сравнение и чек-лист работают в текущей странице и не синхронизируются между устройствами.

Ничего из текущего расширения не публикуется на внешний хостинг. Браузерная визуальная проверка остаётся ограниченной сохранённой политикой доступа к localhost; сборка, проверка TypeScript, тесты и локальная подготовка проверяются отдельно.
