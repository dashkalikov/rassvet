# РАССВЕТ — локальный учебный проект

Для запуска нужен Node.js 24 или новее. После клонирования откройте терминал в корне репозитория и выполните:

```sh
npm ci
npm run local
```

На Windows после `npm ci` можно запустить `Start-Rassvet.cmd` двойным щелчком. Оставьте окно сервера открытым и перейдите по напечатанному адресу, обычно `http://127.0.0.1:5173/`. Для остановки нажмите `Ctrl+C`.

Приложение запускается локально. Аккаунты, заявки и обращения хранятся в `.wrangler/state/`, которая создаётся при запуске и исключена из Git.

Для демонстрации после первого запуска можно остановить сервер и выполнить `npm run demo`, затем снова `npm run local`. Будут добавлены 24 вымышленных клиента и инженер. То же действие доступно в инженерном портале: «Сеть → Добавить демоаккаунты».

Клиент: `anna.demo@example.test`. Инженер: `engineer.demo@example.test`. Учебный пароль обоих аккаунтов: `Rassvet-Demo2026!`. Данные для входа работают после подготовки демонстрационных аккаунтов; права администратора выдаются отдельно по инструкции в OPERATIONS.md.

Проверки: `npm test`, `npm run typecheck`, `npm run build`, затем `npm run test:http`. HTTP-проверка использует отдельную временную базу и не затрагивает ваши аккаунты.
