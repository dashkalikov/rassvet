# Служебные кабинеты РАССВЕТА

На странице входа доступны три кабинета. Клиенты регистрируются через «Создать аккаунт». Администратор может открыть витрину, личный кабинет, инженерный портал и управление в одном сеансе. В шапке используйте кнопку «Кабинеты» для перехода между тремя кабинетами.

## Первый вход

1. Запустите проект обычным способом и создайте клиентский аккаунт, который будете использовать для администрирования.
2. Остановите сервер и выполните команду в папке `rassvet-web`, подставив почту этого аккаунта.

   ```sh
   npm run local -- --make-admin admin@example.com
   ```

3. Запустите сервер, если он остановлен. В форме входа выберите «Администратор» и введите пароль аккаунта.
4. Для входа с правами инженера зарегистрируйте отдельный аккаунт. В кабинете администратора выберите «Аккаунты → Открыть профиль → Сменить роль на „Инженер“» и подтвердите действие. Выйдите из аккаунта администратора, откройте `/auth?portal=engineer` и введите почту и пароль аккаунта инженера.

Команда создаёт права первого администратора в этой базе. Права администратора защищены от смены и блокировки из веб-интерфейса. Назначение инженера, отзыв роли и блокировка завершают действующие сеансы целевого аккаунта. Изменения доступа видны в журнале.

В профиле клиента или инженера раздел «Сброс пароля» позволяет задать новый пароль. Подтвердите действие своим паролем администратора. Старый пароль и действующие сеансы пользователя перестанут работать. В журнале сохраняется факт сброса, пароли туда не попадают. Свой пароль администратор может изменить в обычных настройках профиля.

## Метрики и подписки

- «Сеть» показывает запросы API, ошибки 4xx и 5xx, среднее и максимальное время ответа. Можно включить обновление панели раз в минуту.
- «Клиенты и подписки» показывает имена, регистрации, текущие статусы и историю изменений. Учебные записи помечены «Демо». Email видны администратору в кабинете управления.
- В «Управление → Подписки» можно активировать, приостановить, возобновить или отменить учебную подписку. Введённые до обновления заявки сохраняются. Для них в историю переносится дата создания, а последующие переходы записываются при изменении статуса.
- В разделе «Орбиты» есть плоская карта, вращаемый глобус, график с выбором до четырёх аппаратов и каталог с поиском по NORAD. Кнопка обновления сохраняет полученные эпохи CelesTrak в локальной базе. Координаты, высота и скорость рассчитаны SGP4. Если элементы старше семи суток, карта открывается на эпохе выбранного аппарата. График использует локальную историю и оставляет разрывы между наблюдениями, если прошло больше двух суток.

CSV доступен отдельно для дневных и часовых метрик, истории клиентов, подписок, тарифов, каталога, истории выбранной орбиты и журнала доступа. Сводная выгрузка включает JSON и текстовый формат Prometheus. Файлы скачиваются из служебного кабинета с действующим сеансом.

## Демонстрация и диагностика

В «Сеть» и «Подписки» доступна кнопка «Добавить демоаккаунты»: 24 клиента с российскими именами и подписками разных статусов, а также инженер Алексей Соколов. Клиент `anna.demo@example.test`, инженер `engineer.demo@example.test`, учебный пароль `Rassvet-Demo2026!`. Повторная подготовка не перезаписывает существующие пароли и статусы. Локальная команда: `npm run demo` после первого `npm run local`.

По умолчанию графики нагрузки API используют подписанный демонстрационный набор. «Измерения» показывает только фактическую работу локального приложения. Тестовая нагрузка не записывается в таблицу измерений. В выгрузках режим указан в JSON `dataMode`, HTTP-заголовке `X-Rassvet-Data-Mode`, имени файла и метрике Prometheus `rassvet_data_mode`. Для выгрузки демонстрационной нагрузки добавьте `demo=1`; без него экспорт использует измерения.

Кнопка «Проверить систему» проверяет доступность базы, считает орбитальные аппараты и элементы старше семи суток. Реакция системы отображается в уведомлениях успеха, предупреждения и ошибки. Ошибки можно закрыть вручную.

## Орбитальная лаборатория

В каталоге добавляйте спутники в избранное звёздочкой. Избранное и настройки слоёв общие для таблицы, карты и глобуса и хранятся в этом браузере. «Только избранные» фильтрует аппараты на карте. Доступны подписи, индивидуальные цвета или цвета групп запуска, зоны радиовидимости и угол места от 0° до 90°. Зоны показывают сферическую геометрию радиовидимости, а не фактическую зону обслуживания сети.

В графике можно сравнить до четырёх аппаратов, быстро взять их из избранного и выбрать 7, 30, 90 дней или весь доступный архив. В проект включён снимок 12 865 наблюдений для 30 аппаратов из [findrassvet.ru, В. Булыбенко](https://findrassvet.ru/) от 18.11.2026. Полуось по Кеплеру приведена к используемым константам; источник и метод указаны в `lib/data/findrassvet-source.json`. Хранятся до 500 последних уникальных эпох каждого аппарата. Обновление CelesTrak продолжает локальную историю. Пробелы длиннее двух суток не соединяются.

Карты, глобус, каталог и графики можно развернуть кнопкой «На весь экран» и свернуть кнопкой или Esc. При отсутствии Fullscreen API используется полноэкранная панель внутри приложения.

Клиент может выбрать из 81 города или указать другой адрес, оформить заявку, затем активировать учебную подписку в личном кабинете. Активация фиксируется в истории; реальных платежей нет.
