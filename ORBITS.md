# Орбиты и спутники

Откройте **Технология → Орбиты и спутники** или карточку на главной странице. Прямой адрес после обычного локального запуска: `http://127.0.0.1:5173/orbit`.

Это отдельный интерфейс лаборатории с кнопкой «На сайт», но с общим запуском РАССВЕТА. На Windows достаточно `Start-Rassvet.cmd` в родительской папке. На Linux и Windows из `rassvet-web`: `npm run local`. Дополнительный Python-сервер не нужен. Приложение не публикуется.

## Возможности

- Вращение глобуса мышью, касанием и стрелками клавиатуры; масштаб и центрирование на выбранном аппарате.
- Плоская карта трассы над поверхностью и орбитальный вид с учётом высоты. Показаны прошедшие и следующие 45 минут.
- Поиск по названию и NORAD, сортировка по названию, номеру или высоте орбиты, избранное.
- Пауза, движение времени ×1 / ×10 / ×60, сдвиг на ±90 минут, возврат к текущему времени или эпохе элементов.
- Высота, скорость, широта, долгота, период, наклонение, перигей, апогей, полуось и история уникальных эпох. Темп изменения вычисляется регрессией только при наличии хотя бы трёх эпох.
- Импорт TLE/3LE/2LE (`.tle`, `.txt`) и OMM JSON (`.json`), до 1 МБ и 200 аппаратов. TLE проверяется по контрольным суммам; OMM поддерживает шестизначные номера. Файл обрабатывается в браузере.
- Выгрузка отфильтрованной таблицы в CSV. Каталог, история и избранное сохраняются в этом браузере (`rassvet-orbits-v1`). Аккаунт не требуется.
- Светлая и тёмная темы, общие с основным приложением.

## Что использовано из satellite-tracker

Исходная папка `../satellite-tracker` относительно корня `rassvet` не изменялась. Из неё перенесены сценарии карты, таблицы, истории большой полуоси, расчёт периода/перигея/апогея и линейная регрессия темпа изменения. История отобрана по 30 номерам полученного каталога: 15 исходных записей для 15 аппаратов, повторы удалены. Исходные даты архива сохранены, их первичный источник не перепроверен; это не полный архив наблюдений.

Python SGP4 и упрощённое преобразование координат заменены браузерным SGP4 из Satellite.js с геодезической широтой. Исходный трекер больше не нужен рядом для запуска РАССВЕТА. Избегаются прежние зависимости от `localhost:5000`, CDN Leaflet/Chart.js и сетевых тайлов.

## Данные и ограничения

Встроенный каталог: 30 записей CelesTrak, сохранённых 4 ноября 2026 года. Это снимок, а не обещание всегда актуального состава группировки. Эпоха каждого аппарата видна в карточке и таблице. Положение рассчитывается по модели, а не принимается как телеметрия. При удалении от эпохи более чем на 7 суток показывается сообщение о неточности; можно вернуться к эпохе или импортировать новые элементы. Видимость аппарата на карте не означает наличие связи или покрытия.

При первом открытии сеть не используется. Кнопка «Обновить каталог» вызывает локальный `/api/orbits/catalog`, который загружает только фиксированный запрос [CelesTrak NAME=RASSVET, FORMAT=JSON](https://celestrak.org/NORAD/elements/gp.php?NAME=RASSVET&FORMAT=JSON). Сервер объединяет параллельные запросы, кэширует результат на два часа и не повторяет запросы после ошибки в этом интервале. Браузер также сохраняет время попытки. После перезапуска локального сервера его кэш начинается заново. Без интернета остаются доступны сохранённые данные и импорт.

Источники и библиотеки:

- [CelesTrak: формат GP/OMM](https://celestrak.org/NORAD/documentation/gp-data-formats.php), [правила обновления](https://celestrak.org/usage-policy.php).
- [Satellite.js](https://github.com/shashwatak/satellite-js), MIT, версия 6.0.2. Ветка 7 при сборке подтягивала неиспользуемый WebAssembly worker и конфликтовала с текущей сборкой Vite; используется совместимая ветка 6.
- [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/), public domain; локальные контуры земли через `world-atlas` (110m), проекции D3 Geo. Карта не загружает тайлы.

## Проверки

`npm test`, `npm run typecheck`, `npm run build`, `npm run assets:audit`.

Тесты проверяют эталонный вектор SGP4 Vallado, шестизначные номера OMM, UTC, трассу ±45 минут, ошибочные файлы, устранение повторных эпох, регрессию темпа, кэширование источника и стабильный серверный рендер. `node scripts/render-orbit-map.mjs` создаёт статические изображения реального SVG для проверки геометрии в обеих темах; это не проверка поведения в браузере.

Автоматическая проверка браузера в этой среде недоступна из-за сохранённого ограничения на доступ к localhost. Серверный рендер и расчёты проверяются без обхода этого ограничения.
